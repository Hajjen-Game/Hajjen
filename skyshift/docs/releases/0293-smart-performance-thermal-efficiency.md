- C: partition original static opaque road, sides and barrier body into 256m spatial bins by triangle centroid, preserve all original indices/winding/attributes/normals/materials. Bounds computed only from referenced vertices; original complete mesh retained for QA and reflection setup. Temporary visibility only around actual scene render, restored in finally. All tunnel wave updates remain. Cull tunnel module groups only with safe conservative world bounds and no lights/skinned objects/sprites. Transparent rail inlays and depth-offset seams intentionally not split. Geometry remains resident; extra index buffers and draw calls possible.

True behind-wall/around-curve occlusion is NOT implemented: no proof yet that geometry cannot affect visible pixels. Do not use arc-distance cutoffs, fog cutoffs or arbitrary hidden sections. Continue separately only if measured benefit and exact visual proof justify it.
- E: actual built Chrome/SwiftShader checks on 8GB desktop and 4GB touch landscape, same-camera full vs culled render submitted triangles and pixel equality, existing physical jump/HUD proof. Fixed-step and index partition unit tests. Export actual settings, visible/total section counters, presentation cadence and submitted triangle work.
