# PvP 2.5D Custom Mini Heroes

These characters are generated from scratch by the project's own Blender
Python script. No third-party body or character model is used.

v1 archetypes:
- Caster / healer: large readable head, robe, mantle, staff
- Rogue / light melee: narrow torso, short legs, scarf, oversized dual daggers
- Warrior / heavy melee: broad plate torso, large pauldrons, oversized 2H sword

The geometry is intentionally designed for the fixed high 2.5D arena camera:
large simple forms, short proportions, strong color blocks and no hats/hoods.

The generated GLBs are presentation assets only. Combat, timing, targeting and
AI remain owned by the original PvP 2.5D gameplay simulation.
