# Journey 2.0 · authored opening update

**Current revision: 2026-11-04.** See [the focused level-by-level design](JOURNEY_2_0_EARLY_GAME_IDENTITY.md).

The old five reference boards (which used Moon Mirror on 11, 18 and 20) have been replaced with **fifteen exact 7×7 starts** for levels 5–9 and 11–20. The two-swap first Hanabi lesson at level 5 is preserved. Mirror is now parked.

Each reference blueprint fixes the complete family grid, fixture positions and a three-step intended approach. This protects the first decision geometry from random starts, but does not script any swaps, refill patterns or wins. The other levels 1–4 and Koi 10 retain the existing opening generation.

The playtest remains opt-in, unranked and separate from the normal game. Playthrough can continue directly to the next level from the result dialog. Difficulty Lab must still assess complete rounds; a valid opening does not prove full solvability or fun.
