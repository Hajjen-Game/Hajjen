# Jump Solid Body Trial 1.0 — 2026-11-10

Visual A/B experiment requested after the previous chunky Jump adjustment.

- The **ordinary Jump** no longer renders a translucent energy curtain beneath its bright top cap.
- The exact same full-size grounded Jump collider now has an **opaque solid neon body** with a recessed lower face; the existing cap, edge light, and two small horizontal cap engravings remain.
- Same size and same speed scaling as regular Duck (54–71 to 184–221 logical width), unchanged Jump height (59–73), unmodified action physics, Director, and obstacle timing.
- The **Duck** energy field, long Duck Gate, inactive legacy Echo, and other obstacle art are unchanged.
- One existing canvas render path and World Lighting rig. No new objects, textures, generated art, shader, or rendering pass.
- Reversible: the former Jump veil implementation remains available in Git history if player testing prefers it.
